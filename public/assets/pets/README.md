# Pet art

The current game loads these transparent PNGs: `hedwig.png`, `snitch.png`, `cat.png`, `bat.png`, and `dog.png`. Cat and dog are placed on the ground beside the player; the other pets float nearby.

Pigeon art is not included yet, so that choice uses the code-drawn placeholder. Keep replacement exports as PNGs and update the `filename` on the matching entry in `PET_CHOICES` in `src/main.js`.
